# 🎓 Student Management System – Spring Boot

A simple **Student Management System** built using **Spring Boot** and **Thymeleaf**.  
This project allows students to **register**, **log in**, and view their **dashboard** details.

---

## 🚀 Features

- 📝 Student Registration
- 🔐 Student Login
- 📊 Student Dashboard
- 🚪 Logout functionality
- 🎨 Clean UI with animated background
- 🗂️ MVC architecture (Controller, Service, Repository)

---

## 🛠️ Technologies Used

- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Thymeleaf
- HTML & CSS
- Maven
- Git & GitHub
